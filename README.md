# Story Submission Tracker
The Story Submission Tracker is a website that helps writers keep track of stories that are submitted to magazines, contests, agents and publishers. It will keep track of submission deadlines, and which places have been accepted, rejected or need to follow up with a submitted story.

## PWA Features
### Installable application
    An icon stored on the users computer will open a standalone window.

### Manifest
    Determines how the progressive web app will look when installed.

### Service Worker
    This manages the application's interaction between the network and the cache

### Caching
    Saves temporaty files to the browser
    # Static cache
        temporary storage of files that don't update
    # Dynamic cache
        temporary storage for files with reusable data
